# Hackathon brief (Encode × Concordium, autumn 2026)

**Challenge:** "Make your Agents Accountable with Concordium." Take an AI agent you already run (Ethereum, Solana or any of 200+ chains) and make it accountable: prove a verified human stands behind it, let it pay and get paid, leave a record. Build on Concordium testnet with the tools from the six workshops.

## Directions offered (starting points, not tracks)
- Existing agent: add the Verified by Concordium badge, ERC-8004 and x402 to an agent you run elsewhere
- Verified agents: register in the Agent Registry, publish an Agent Card, let other agents check the badge over MCP or A2A before dealing
- Private, verified users: gate a service on a proven attribute (age) via Concordium ID / Verify and Access, storing no personal data
- Agent commerce: agents paying each other for data/APIs/work with x402, sponsored transactions so users never handle fees
- Accountable agents: audit trails for EU AI Act Art. 12 record keeping, lawful route from agent to accountable owner

## Requirements
- Runs on Concordium testnet (free CCD from faucet)
- Meaningful use of ≥1 component: Concordium ID / Verify and Access, Agent Registry + Verified by Concordium badge, x402, Protocol-Level Tokens, sponsored transactions, Agent Registry MCP server
- Submit from the project page by **Wed 9 Dec 2026, 23:59 UTC**

## Submission
1. Description: what, how, which Concordium components
2. Public code repository
3. Demo video ≤ 3 min
4. CCDExplorer link (agent, contract or transactions)
5. Path to production (mainnet, real users)

## Judging (Encode + Concordium review every demo)
- Depth of integration (identity, Agent Registry, agent payments)
- Credible path to production
- It works: clear end-to-end demo of the core flow
- Usefulness: real problem for real people or agents
